# Bayesian PINN Solvers for ODEs

Using the Bayesian PINN solvers, we can solve ODEs and also simultaneously perform
parameter estimation on them.

!!! note "Loading the Bayesian PINN extension"

    The Bayesian PINN solvers (`BNNODE`, `ahmc_bayesian_pinn_ode`) live in a package
    extension. To use them you must load `AdvancedHMC`, `MCMCChains` and
    `LogDensityProblems` alongside `NeuralPDE`:

    ```julia
    using ModelingToolkit, NeuralPDE, SciMLBase, AdvancedHMC, MCMCChains, LogDensityProblems
    ```

    Without those packages loaded, calling `BNNODE(...)` /
    `ahmc_bayesian_pinn_ode(...)` will raise a `MethodError` because the extension
    methods are not in scope.

!!! warning "Bayesian PINNs for PDEs"

    The Bayesian PDE solver (`BayesianPINN` / `ahmc_bayesian_pinn_pde`) of NeuralPDE
    6 was built on the previous PDE parser and was removed in NeuralPDE 7. It will be
    reintroduced on top of the `System` generated by `symbolic_discretize`; see
    https://github.com/SciML/NeuralPDE.jl/issues/1161.

The ODE specific BPINN solver `BNNODE` [refer](https://docs.sciml.ai/NeuralPDE/dev/manual/ode/#NeuralPDE.BNNODE) uses `NeuralPDE.ahmc_bayesian_pinn_ode` at a lower level.
